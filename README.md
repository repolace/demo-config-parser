# demo-config-parser

A tiny `KEY = VALUE` settings-file parser, and an intentionally small target for
[repolace](https://github.com/repolace/repolace), an agent that turns a GitHub issue into a tested
pull request. The open issue describes a real bug; the pull request opened against it is the demo.

This repository exists to show the flow. It is not a library and has no releases.

```bash
python -m pytest
```
